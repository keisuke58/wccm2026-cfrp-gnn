# Concept B — Differentiable FMPE × Phase-Field Inversion (Stage 4-5 research)

First working prototype of `research/STAGE4_5_RESEARCH_CONCEPTS.md` Concept B:
close the inverse↔forward loop with one autodiff gradient by making a coarse
AT2 phase-field forward differentiable, then grounding the posterior over defect
parameters θ in the PDE rather than in labelled examples.

Files: `diff_phasefield.py` (JAX forward `x=F(θ)`), `diff_inversion.py` (MAP +
differentiable-physics posterior + amortised-FMPE baseline + study),
`tests/test_diff_phasefield.py`.  Run on CPU (coarse 28×20 grid, JAX 0.9,
`/home/nishioka/IKM_Hiwi/.venv_jax`).  Regenerate: `python -c "import
diff_inversion as di; di.run_study()"`.

## Forward verification
`jax.grad` of ‖F(θ)−x_obs‖² finite-difference-checks to **rel L2 ≈ 3e-7**
(threshold 1e-2).  Warm forward ≈ 13 ms; forward Jacobian dF/dθ via `jacfwd`.

## Headline result (results/diff_inversion/diff_inversion.png, study.npz)
θ = (cx, cy, size).  FMPE trained on an in-distribution box; OOD = large/edge
defects the amortised model never saw.

| set | method | cx RMSE | cy RMSE | size RMSE | cov90 |
|---|---|---|---|---|---|
| in-dist | FMPE (amortised) | 0.0057 | 0.0066 | 0.0019 | 0.958 |
| in-dist | **DiffPhys** | 0.0006 | 0.0006 | 0.0028 | 1.000 |
| **OOD** | FMPE (amortised) | **0.1438** | **0.1162** | **0.0958** | **0.000** |
| **OOD** | **DiffPhys** | **0.0016** | **0.0019** | **0.0010** | **0.958** |

Punchline: **amortised FMPE degrades ~25× and its 90% intervals collapse to 0
coverage out of distribution**, while the differentiable-physics posterior is
essentially invariant in-dist→OOD (RMSE ~1e-3, coverage ~0.96).  Forward physics
generalises; amortised inference extrapolates poorly — exactly Concept B's
thesis.

## Posterior methods (DPS-lite)
- `laplace_posterior` (PRIMARY): Gauss-Newton/Laplace at the MAP,
  Σ = σ²(JᵀJ + prior)⁻¹ + variance-floor, J = ∂F/∂θ from autodiff.  Calibrated
  (cov ≈ 0.96–1.0), cheap, robust on the razor-sharp likelihood.
- `langevin_posterior` / `svgd_posterior` (secondary): score-based samplers
  driven by ∇_θ log p(x|F(θ)).  They demonstrate the simulation-grounded loop
  but ULA is hard to tune on this stiff narrow basin (documented limitation).

## Honest limitations
- The forward is a **minimal** single-region anisotropic AT2 (scalar Mode-I peel
  proxy elasticity, soft Gaussian seed) — NOT the full Stage-3 multi-ply/interface
  model (`cfrp_phasefield_2d.py`).  It demonstrates end-to-end gradients, not
  quantitative laminate fidelity.
- Synthetic-only: x_obs is generated by the same forward (+ noise); no real NDT.
- Near-deterministic forward ⇒ very sharp posterior; the Laplace covariance has
  a small variance floor so coverage is honest (slightly conservative).
- Very small defects (size ≲ 0.05) are weakly identifiable (forward saturates),
  visible as the one in-dist size-RMSE blemish; OOD (large) defects are exact.
