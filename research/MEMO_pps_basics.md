# メモ：PPS（ポリフェニレンサルファイド）の基本（2026-11-04）

> 研究の対象材料の説明用。一般的な性質は教科書・メーカー資料の通説で、本メモでは一次資料にあたっていない（「一般的な性質」の項）。本研究で使っている数値は、出典のファイルを併記した。

## 1. 何か

- PPS は polyphenylene sulfide の略で、ベンゼン環と硫黄が交互につながった高分子。
- **結晶性**の熱可塑性樹脂である。冷える途中で一部が結晶になり、そのとき体積が縮む（結晶化収縮）。
- 射出成形用には、ガラス繊維で強化した銘柄が多い。GF30 はガラス繊維が重さで 30 % という意味である。

## 2. 一般的な性質（通説、一次資料未確認）

| 性質 | 内容 |
|---|---|
| 耐熱性 | 長期の使用温度が 200 °C 前後と高い |
| 耐薬品性 | 油・燃料・多くの酸やアルカリに強い |
| 難燃性 | 難燃剤なしで燃えにくい（UL94 V-0 相当の銘柄が多い） |
| 寸法安定性 | 吸水がごく小さく、湿気による寸法変化が小さい |
| 用途 | 自動車のエンジンまわり、センサー・コネクタのケース、電子部品 |

## 4. この研究で PPS の何が効くか

- **ガラス繊維の向き**：繊維の向いた方向は縮みにくく、その違いが残留応力と反りを生む。
- **結晶化**：結晶化の進み方（速度定数）と収縮の量が、無応力温度と残留応力の大きさに効く。PPS の結晶化の定数は文献値（`validation/pps_crystallization_kinetics.py`）。
- **応力緩和**：*T*<sub>g</sub> より上では樹脂が柔らかく、力が逃げる。PPS の粘弾性（DMA）のデータは未入手で、デンソー様に依頼中。
