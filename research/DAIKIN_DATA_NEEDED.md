# ダイキン CFRTP：モデル確定に必要なデータ（依頼リスト）

現状、フッ素樹脂×CF の実系データは**専有で未入手**。`abaqus/cfrtp_daikin_pfa_hl.inp`
は **PFA 相当のプレースホルダ**（推定値、未検証）で回るようにしてあり、下のデータが
入り次第そのまま定数を差し替えれば「検証済み・定量」になる。

> 手法自体は炭素/PEEK 公開データで検証済み（`validation/`、HL で Tp≈305℃ を再現）。
> フッ素樹脂は PEEK ほど公開データが無いのが律速。

## 1. 材料同定（まず最初に）
- 対象樹脂系（**PFA / FEP / ETFE / 変性フッ素樹脂**のどれか）、グレード、CF 種・体積含有率、積層構成。

## 2. 結晶化（HL K(T) の校正）
- **DSC 非等温**：数種の冷却速度（例 2/5/10/20/40 ℃/min）での結晶化発熱ピーク **Tp** と相対結晶化度 α(T)。
  → `validation/peek_reference_Tp.csv` 形式（`rate_C_per_min,Tp_C`）にすれば **RMSE 自動**、HL の `K0/Kg/U*` をフィット。
- **Tm・Tm0（平衡融点）・Tg**、絶対結晶化度 X∞、結晶化収縮（BETA）。

## 3. 粘弾性（Prony/WLF の校正）
- **DMA** 温度掃引（貯蔵弾性率・tanδ）→ 緩和スペクトル（Prony τ_k, g_k）と WLF（C1,C2,Tref）。

## 4. 熱・弾性物性
- **CTE(T)**（フッ素樹脂は高 CTE＝残留応力の主因。今は 100e-6 /K 仮）、直交異方性弾性定数 E1..G23。

## 5. 界面・破壊（ダイキンの本丸）
- **ILSS**（表面処理あり/なし）、混合モード靭性 **G_Ic, G_IIc, η**（B-K）、界面の残留せん断。

## 6. 検証用の巨視量
- **残留応力・反り**の実測（非対称積層など）→ FE 予測と突き合わせ。
- 成形条件（冷却速度・工具拘束・保圧）と、可能なら**ボイド率・含浸**（開繊効果）。

## 差し替え手順（データが来たら）
1. `abaqus/gen_inp.py` の `gen_daikin_pfa_hl` の PROPS を実測値に置換 → `python3 gen_inp.py` で再生成。
2. `validation/peek_reference_Tp.csv` 相当を作り HL を再フィット（`K0/Kg/U*/Tm0`）。
3. `bash run_all.sh daikinpfa` で実走、残留応力・反りを実測と比較。
