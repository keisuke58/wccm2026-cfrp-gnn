# デンソー様のデータの受け取り形式と、受け取り後の手順（2026-11-04）

> 目的：データを受け取った日に、確認から補正までを一度に回す。書式が違っても受け取れるが、この形だと変換の手間と誤りが減る。
> ひな形：`data/denso_templates/*.csv`（`#` で始まる行は説明。`EXAMPLE` の行は例で、読み込み時に無視される）。

## 1. ファイル（どれか 1 つからでよい）

| ファイル | 1 行の中身 | 列 | 単位 |
|---|---|---|---|
| `specimens.csv` | 試験片 1 つ | specimen, thickness_mm, mould_T_C, melt_T_C, annealed, anneal_T_C, note | mm、°C |
| `hole_drilling.csv` | 穿孔の 1 段 | specimen, depth_mm, ch1_td, ch2_45, ch3_md | mm（掘った面から）、µε |
| `orientation_profile.csv` | 板厚方向の 1 点 | specimen, depth_mm, a_xx, a_yy, a_zz（空欄可） | mm（掘った面から）、無次元 |
| `warpage_points.csv` | 反りの 1 点 | specimen, x_mm, y_mm, w_mm | mm（x が MD、y が TD、w が面外） |

- ゲージは既報と同じ FRAS-2 型を想定（Ch.1 が TD、Ch.2 が 45°、Ch.3 が MD）。別の型なら型式と向きを `note` に書いていただく。
- 配向は流動解析（Ansys など）または X 線 CT の値。要素ごとの出力しかない場合は、そのファイルのままでよい（こちらで板厚方向の分布に直す）。
- 3 次元の部品の反りは、点群（x, y, z と変位）とメッシュのファイルがあればよい（形式はご相談）。

## 2. 受け取り後に自動で行うこと（`validation/denso_intake.py`）

```bash
python3 validation/denso_intake.py --dir 受け取ったフォルダ --out results/denso_intake/日付
```

1. **書式と値の確認**：列の有無、数値か、範囲（解放ひずみ 5000 µε 以内、配向 0〜1 で *a*<sub>xx</sub> + *a*<sub>yy</sub> ≤ 1.02、板厚 0.5〜10 mm）、深さの順、試験片名の対応。問題は一覧にするだけで、勝手に直さない。
2. **穿孔法**：影響関数（fifa §16）で解放ひずみを予測し、
   - H1：実測に最も合う無応力温度 *T*<sub>0,eff</sub>、
   - H2：共通の倍率（*T*<sub>0</sub> = 180 °C に対して）、
   - H3：MD のゲージだけで *T*<sub>0,eff</sub> を決め、TD と 45° を予測したときの誤差。
3. **反り**：測定点に二次曲面を当てはめて曲率を求め、積層理論の予測（*T*<sub>0</sub> = 180 °C と、穿孔法で求めた *T*<sub>0,eff</sub>）と比べる。
4. 出力：`report.md`（英語の短い要約）、`report.json`、`hole_drilling.png`。

## 4. 正直な限界

- 影響関数は既報の板（3.08 mm）・ゲージ・剛性で計算したもの。板厚・ゲージ・材料が違う場合は近似で、fifa §16 で計算し直す（スクリプトが警告を出す）。
- 弾性の連鎖で、応力緩和は *T*<sub>0,eff</sub> にまとめて扱う。
- 反りの予測は自由な平板の積層理論で、部品の面内の形は考えない。
- このスクリプトの結果は、実データを入れるまでデンソー様の結果ではない。
