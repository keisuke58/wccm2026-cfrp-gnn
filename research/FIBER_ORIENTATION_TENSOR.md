## 1. 配向テンソル（Advani–Tucker, 1987）とは

繊維1本の向きを単位ベクトル **p** で表し、ある点まわりの向きの分布を配向分布関数 ψ(**p**) とする。
これをそのまま持ち歩くのは重いので、**モーメント（テンソル）で縮約**する：

```
2階:  a_ij    = ∫ p_i p_j         ψ(p) dp
4階:  a_ijkl  = ∫ p_i p_j p_k p_l ψ(p) dp
```

実務で「配向テンソル」と言えば**2階の a_ij**。商用ソルバが出すのもこれ。

### 性質（制約として効く）
- **対称**：a_ij = a_ji → 3D で独立成分は 6 個（a11, a22, a33, a12, a13, a23）
- **トレース = 1**：a_ii = 1（**p** が単位ベクトルなので必然）→ **実質の自由度は 5**
- **半正定値**：固有値 λ1 ≥ λ2 ≥ λ3 ≥ 0、かつ Σλ = 1
- **固有ベクトル = 主配向方向**、**固有値 = その方向への揃い具合**

### 代表的な状態（直感のため）
| 状態 | a_ij | 意味 |
|---|---|---|
| x 方向に完全配向 | diag(1, 0, 0) | 全繊維が同じ向き |
| 3D ランダム（等方） | diag(1/3, 1/3, 1/3) | 向きがバラバラ |
| 面内ランダム（xy 面） | diag(1/2, 1/2, 0) | 面内でバラバラ、面外成分なし |

→ **λ1 が 1 に近いほど強配向、1/3 に近いほど等方**。これが「揃い具合」のスカラー指標になる。

## 2. どう作られるか（Ansys 側が何を解いているか）

### Folgar–Tucker 方程式
流動場 **v** の中で a_ij が時間発展する：

```
Da_ij/Dt = −½(ω_ik a_kj − a_ik ω_kj)                     ← 渦度による回転
         + ½λ(γ̇_ik a_kj + a_ik γ̇_kj − 2 a_ijkl γ̇_kl)   ← ひずみ速度による伸長・整列
         + 2 C_I γ̇ (δ_ij − 3 a_ij)                       ← 繊維同士の相互作用（回転拡散）
```
- ω：渦度テンソル、γ̇：ひずみ速度テンソル、γ̇：そのスカラー等価量
- λ = (r²−1)/(r²+1)：繊維のアスペクト比 r による形状係数
- **C_I：相互作用係数**（Folgar–Tucker の経験パラメータ）

### ★閉包問題（closure problem）
**a_ij の式に 4階の a_ijkl が出てくる**ので、そのままでは閉じない。
4階を2階で近似する**閉包近似**が必要：
- 線形 / 二次 / ハイブリッド（Advani–Tucker）
- **直交閉包**（ORW, ORW3 — Cintra & Tucker）
- **IBOF**（不変量ベース最適フィッティング — Chung & Kwon）
- 近年は**ニューラルネットで 4階↔2階を学習する閉包**も提案されている（直交閉包より高速との報告）

### ★配向が速く進みすぎる問題と、その補正
標準の Folgar–Tucker は**濃厚系で配向変化を速く見積もりすぎる**。実務の補正：
- **RSC**（Reduced Strain Closure, Wang–O'Gara–Tucker 2008）：
  **固有値の成長だけをスカラー κ で遅くし、固有ベクトルは変えない**
- **ARD**（Anisotropic Rotary Diffusion, Phelps–Tucker 2009）：
  スカラー C_I を**テンソル**に拡張。長繊維向け
- **ARD-RSC**（両者の併用）、**iARD-RPR**（Tseng ら, Moldex3D）など

### ★ここが転移学習で効いてくる：**Ansys データ自体がモデル依存**
配向場は「計算で出た真値」ではなく、**モデル（FT / ARD-RSC / iARD など）× 閉包 × フィット済みパラメータ
（C_I, κ など）**の産物。つまり：

> **Ansys データには、離散化誤差だけでなく「配向モデルの誤差」が乗っている。**
> 「Ansys で学習 → 実験で合わせる」という転移は、**その両方をまとめて補正する**ことになる。

→ 先方に **どのモデル・どの閉包・どのパラメータか**を聞いておくべき。
   同じ形状でもモデルが違えば配向場は変わるので、**データの素性が変われば転移の前提も変わる**。

## 3. スキン–コア構造（実務上いちばん効く事実）

射出成形品は**板厚方向で配向が大きく変わる**：
- **表層（スキン）**：壁面せん断が強く、**流動方向に強配向**
- **中心（コア）**：ファウンテンフローと伸長流の効果で、**流動と直交方向寄り**になることが多い

→ 帰結が2つあり、どちらも本件に直撃する：
1. **a_ij は「点の値」ではなく「板厚方向のプロファイル」**。入力を1点の値に潰すと、スキン–コアの情報が消える。
2. **実験が「点で測ったもの」なら、それが表面なのか内部なのかで見ているものが違う**。
   表面測定ならスキンを見ており、コアの配向は見えていない。
   → [`DENSO_RA_RESIDUAL_STRAIN.md`](./DENSO_RA_RESIDUAL_STRAIN.md) §8 の「測定法を確認」はここに直結する。

## 4. ★ML の入力としてどう表現するか（設計判断）

**ここが本題**。検索範囲では直接の指針が見つからなかったので、制約から導く。
先行例として、ゲート設計の研究が**節点座標＋各節点の配向テンソルをそのまま特徴量**にして
Gradient Boosting に入れている例はある（＝(a) の素朴な採用）。

### (a) 生の6成分をそのまま入れる
`[a11, a22, a33, a12, a13, a23]`
- ✅ 単純。ソルバ出力そのまま。情報を落とさない。先行例もある
- ❌ **座標系に依存**（frame-indifferent でない）。回転させると成分が変わるので、
  ネットワークは「回転したら答えもこう変わる」を**データから学ぶ羽目になる**
- ❌ トレース=1 の拘束が入っていない（入力側なので致命的ではないが、正規化の際に注意：
  **成分を独立に標準化すると拘束が壊れる**）
- ⚠️ メッシュごとに局所座標系が違うと成分が比較不能。**一貫した大域座標系で揃えること**

### (b) 固有値＋主方向（固有ベクトル）
- ✅ 物理的に解釈しやすい（揃い具合＋向き）
- ❌ **固有ベクトルの符号と順序が一意でない** → 連続的に動かすと**不連続にジャンプ**する
- ❌ **λ1 ≈ λ2 の縮退近傍で主方向が悪条件**になり、わずかな変化で方向が飛ぶ
  （面内ランダムに近い領域＝まさに実部品で起きる）
- → **学習対象の写像に人工的な不連続を持ち込むので、素直には勧めない**

### (c) 不変量だけ（λ1, λ2 か、a の第2・第3不変量）
- ✅ 回転不変。コンパクト（トレース=1 なので λ1, λ2 の2個で足りる）
- ❌ **方向情報を捨てる**。残留ひずみは**異方的**（方向を持つ量）なので、
  方向を捨てた入力から方向を持つ出力は原理的に出ない
- → **単独では不可**。出力も同じ主軸系で表すなら成立しうるが、話が複雑になる

### (d) ★物理を通した表現：配向平均した異方性物性
a_ij から、UD（横等方性）の素材物性を **Advani–Tucker の配向平均**で畳み込み、
**実効剛性 C_ijkl と実効熱膨張 α_ij** に変換して、それを入力にする。
- ✅ **残留ひずみが配向に依存する"経路"そのもの**を入力にできる。
  配向は α と C を通してしか効かない（異方的な収縮と拘束のミスマッチが残留ひずみを生む）
- ✅ 物理主役・ML従属という本リポの方針とも整合
- ❌ UD 構成素材の物性が要る。配向平均という**モデル仮定が1つ増える**
- → **(a) と並べて比較する価値が高い**

### (e) 回転同変（equivariant）ネットワーク
テンソル入力・テンソル出力を、回転同変な構造で扱う。
- ✅ frame indifference が**構成上保証**される。符号・順序の曖昧さも無い
- ❌ 実装コストが高い。**今年度は研究会発表まで**という線に対して重い
- → 今期は見送り、将来の選択肢として置く

## 5. 推奨（叩き台）

1. **ベースライン＝(a) 生6成分**。ただし **一貫した大域座標系**で揃え、
   **正規化はトレース拘束を壊さない形**にする。先行例もあり、まず動かすならこれ。
2. **対照群＝(d) 配向平均した α_ij（と必要なら C）**。物理を通した特徴量。
   (a) より少ない学習データで効く可能性があり、**効けばそれ自体が主張になる**。
3. **(b) は避ける**（縮退と符号の不連続）。**(c) 単独も避ける**（方向が消える）。
4. **入力と出力の座標系を必ず揃える**。残留ひずみもテンソル量なので、
   入力を大域系で与えて出力を局所系で予測する、のような取り違えをしないこと。
5. **スキン–コアを潰さない**。板厚方向のプロファイルを持つなら、
   1点に平均せず**層として与える**か、板厚座標を入力に足す。

## 6. 実務：Ansys 側から何が出てくるか
- Ansys には **Moldflow → 構造メッシュ**へ配向データを渡す仕組みがある
  （Moldflow の XML に入った配向テンソルを受け取り、**最大固有値の主軸**に沿って写像する）。
- **流動解析メッシュと構造解析メッシュは粒度が違う**ので、写像の適合性チェックが要る
  （構造側が粗すぎると配向場が潰れる）。
- 反り（warpage）予測には**流動段階で計算した配向を構造段階へ持ち込む**必要がある、という点は
  ドキュメント側でも明示されている。残留応力も反りの駆動要因。
- ⚠️ ただし **Ansys Mechanical で a11/a22 をどう受け渡すかの一次情報は未確認**
  （見つかったのは LS-DYNA 向けの Moldflow-to-Solid と Autodesk 側の資料）。**先方の実際のワークフローを要確認**。

## 7. 先方に確認したいこと（§4-6 から出てくる）
1. **配向モデルと閉包**：FT か ARD-RSC か iARD-RPR か。閉包は何か。**C_I・κ の値**は。
2. **配向データの粒度**：節点ごとか要素ごとか。**板厚方向に何層持っているか**（スキン–コアが解像されているか）。
3. **受け渡し形式**：配向テンソルの6成分が出るのか、主軸＋固有値なのか、座標系は何か。
4. **繊維の素性**：ガラスか炭素か、短繊維か長繊維か、アスペクト比、体積含有率。
   （ARD 系が要るかは繊維長で変わる）
5. **実験の点の位置**：表面か内部か、板厚のどこか。**スキンを見ているのかコアを見ているのか**。
6. **残留ひずみの成分**：テンソルで欲しいのか、等価スカラーか、特定方向か。
