# 予測の幅（不確かさ）— GF/PPS 板（2026-11-08）

スクリプト：`validation/denso_uncertainty.py`（結果 `results/denso_uncertainty/uncertainty.json`）、
図：`slides/figure_sources/denso_uncertainty_fig.py` → `slides/figures_paper/uncertainty.png`。

## 何をしたか
材料定数を、仮定した幅の中で一様に 400 回ばらつかせた。予測は次の 2 通りで比べた。
- **P（予測だけ）**：無応力温度は既報の仮定どおり 180 °C とし、実測は使わない。
- **I（実測で温度を決める）**：サンプルごとに、既報の穴あけ解放ひずみ（図からの読み取り値）に
  合うように T0_eff を決め直す。読み取りの誤差として 10 µε のノイズを毎回加える。

ばらつかせた範囲はすべて仮定で、データに基づくものではない。
| 定数 | 範囲 |
|---|---|
| 樹脂の弾性率 | ×0.85–1.15 |
| 樹脂の熱膨張 | ×0.90–1.10 |
| ガラスの弾性率 | ×0.95–1.05 |
| 繊維体積含有率 Vf | 0.15–0.21 |
| アスペクト比 | 12–22 |
| 中心層の幅 w | 0.75–1.25 |
| 配向の強さ m | 0.85–1.10 |
| カタログ強度 | 155 MPa ×0.90–1.10（代替グレード 1130T6） |

## 結果（中央値 [5–95 %]）
| | P 予測だけ | I 実測で温度を決める |
|---|---|---|
| T0_eff | 180 °C（固定） | 147 [135, 160] °C |
| 板の最大残留引張応力 | 35.1 [27.7, 43.8] MPa | 24.0 [20.1, 29.0] MPa |
| 強度 MD（基準 A） | 112 [92, 132] MPa | 127 [108, 142] MPa |
| 強度 TD（基準 A） | 104 [85, 127] MPa | 124 [105, 143] MPa |
| 残留応力による強度低下 MD | −28 [−38, −19] % | −19 [−26, −14] % |
| 残留応力による強度低下 TD | −37 [−48, −28] % | −25 [−31, −21] % |

- **整合（U0）**：定数を基準値にすると、T0_eff は 143.0 °C（既存 142.9 °C）、強度は 124.8 / 122.8 MPa
  （既存 124.8 / 122.9 MPa）になり、既存の結果と一致した。
- **T0_eff の幅（U1）**：定数を基準値にしたとき、68 % 区間は 141–145 °C。σ は最適点の RMSE 15.6 µε とした。
  定数のばらつきまで入れると、幅は 135–160 °C に広がる。定数の不確かさのほうが、読み取り誤差より大きく効く。
- **示せたこと**：実測を使うと、残留応力の 5–95 % 幅は 16.1 MPa から 8.9 MPa に縮む（0.55 倍）。
  強度の低下率の幅も、MD で 19 ポイントから 12 ポイントに縮む。
- **示せていないこと**：強度そのもの（MPa）の幅は、あまり縮まない（MD で 40 MPa から 34 MPa）。
  一番効いているのはカタログ強度の不確かさ（順位相関 +0.84）で、穴あけ測定では減らせない。
  減らすには、方向別の引張試験（デンソー様のデータ）が要る。
- **効く定数（U3、I の場合）**
  - 残留応力：樹脂の弾性率 +0.68、Vf +0.45、中心層の幅 +0.40。測定はひずみなので、応力に変えるには剛性が要る。
    つまり DMA のデータが一番効く。
  - T0_eff：樹脂の熱膨張 −0.70、アスペクト比 −0.51。熱膨張の不確かさは、温度の推定に吸収される。
- **3 次元部品（U4、Moldflow データ 196 形状、実測ではない）**：反りの相対誤差の中央値 [5–95 %] は、
  補正なし 54 [42, 63] %、測定なし（他の部品の倍率）22 [14, 54] %、10 点で補正 17 [9, 35] %。
  倍率は 2.02 [1.49, 2.49]。

## 正直な限界
- 定数の範囲は推測で、互いに独立と仮定した。
- 影響関数 G は既報の剛性分布を持つ。全体を一様に拡大縮小する場合は正確だが、分布の形が変わる場合は正確でない。
- 実測は 1 枚の板の、図からの読み取り値だけ。
- 弾性の連鎖で、緩和は T0_eff だけで表している。
- 強度は基準 A（数値例）だけ。基準 B は失敗している（MEMO_denso_strength.md）。
- ここで出した幅はモデルの幅であり、実測のばらつきではない。

## デンソー様のデータが来たら
- DMA（樹脂の剛性の温度依存）：残留応力の幅が一番縮む。
- 方向別の引張強度：強度の MPa の幅が縮む。
- 同じ条件の板を複数枚測ったデータ：実測のばらつきと、モデルの幅を比べられる。
