# 差別化アイデア: 弱形式 FEM × 演算子学習 × オンライン適応（半導体GAA）

> ねらい: Otsuki & Mori (WCCM-ECCOMAS 2026, STS415) の「**MC ループ内の有限差分
> ポアソンを PI-DeepONet で代替**」を**そのまま踏襲しない**。FEM（弱形式・非構造メッシュ・
> 要素剛性・a-posteriori 誤差評価）を方法の中心に据えることで、応用ではなく**原理レベルで
> 別物**にする。実装デモ: [`pi_deeponet_fem_gaa.py`](../pi_deeponet_fem_gaa.py)。

## 0. 何が「パクリでない」のか — 一枚で

| 観点 | Otsuki & Mori (参照) | 本アイデア (A+D+B) |
|---|---|---|
| 離散化 | 有限差分・**強形式**（点ごとの ∇²φ 残差, PINN型） | **FEM 弱形式 (Galerkin)**：試験関数との積分残差 |
| 物理損失 | 強形式 PDE 残差（自動微分でラプラシアン） | **組立済み FE 残差** r = K(ε)φ − Mρ（要素剛性を経由） |
| メッシュ | 構造格子前提 | **非構造 P1 FE メッシュ**（GNN branch が任意メッシュを摂取） |
| 誤差評価 | 予測残差の大小で判定 | **FE a-posteriori 誤差評価**が「メッシュ細分化」と「追学習トリガ」を統一 |
| 係数 | 一様 ε 想定が容易 | **可変誘電率 ε(x)**（GAA の酸化膜/Si 同心構造）を剛性に反映 |
| 駆動 | Monte Carlo 輸送ループ | ドリフト拡散(FE-TCAD)を模した準定常ループ |

要は「**強形式 FD → 弱形式 FEM**」への置換が新規性の核。WCCM（計算力学）の聴衆は
FEM・変分・誤差評価・適応細分化を共通言語とするため、この軸は場として最も自然で、
かつ元研究と衝突しない。

## 1. 三つの構成要素

### A. 弱形式 (Galerkin) を物理損失に
支配方程式 −∇·(ε∇φ)=ρ の弱形式は、試験関数 v に対し
∫ε∇φ·∇v dΩ = ∫ρ v dΩ。P1 有限要素で離散化すると
**K(ε) φ = M ρ**（K: 剛性行列, M: 質量行列）。
演算子ネットが節点電位 φ を出力し、物理損失を**組立済み FE 残差**

  L_pde = ‖ (K(ε)φ − Mρ)|_free ‖² / ‖(Mρ)|_free‖²

とする。これは点ごとのラプラシアン（強形式 PINN）ではなく、**実 TCAD が解く弱形式
そのもの**。可変 ε(x) は要素ごとの剛性 K_e = ε_e(bᵀb+cᵀc)/(4A) に自然に入る
（一様 FD ステンシルが均してしまう不連続界面を、要素単位で正しく扱える FEM の利点）。

### D. FE a-posteriori 誤差評価 → 細分化とオンライン追学習を統一
残差ベース誤差指標 η = ‖(Kφ−Mρ)|_free‖ / ‖(Mρ)|_free‖ を各ステップで評価。

- η が大 → その節点/要素は**メッシュ細分化の候補**（古典的 FE 適応の指標そのもの）。
- 同じ η が閾値超過 → **厳密 FE 解 K_ff φ_f = (Mρ)_f を起動**（オラクル）し、
  得られた (ρ, φ) を**オンザフライで追学習**。

一つの誤差指標が「どこを細かくするか（AMR）」と「いつ厳密解を呼び追学習するか
（online）」を同時に駆動するのが要点。適応が進むほど**厳密解の起動率が低下**する
のを主要指標とする。

### B. GNN branch（本リポジトリと直結）
Branch を **FE メッシュのグラフ**（節点=FE節点, 辺=メッシュ辺）上のメッセージ
パッシングにし、ρ を任意メッシュ上の**節点場**として摂取。読み出しは固定センサ節点
（粗い部分格子）での GNN 埋め込み ＝ 位置情報を保つ古典 DeepONet branch の GNN 版
（global mean-pool だと電荷の位置がぼける）。Trunk は連続座標（Fourier 特徴つき）を
取り、φ(y)=⟨branch(ρ), trunk(y)⟩＋Dirichlet ハードマスク。
→ 本 repo の mesh-agnostic GNN（`mesh_agnostic_gnn.py`, `dual_stream_gnn.py`）と地続きで、
CFRP×GNN で培った「非構造メッシュ上の演算子学習」の知見をそのまま持ち込める。

## 2. デモ実装と結果

[`pi_deeponet_fem_gaa.py`](../pi_deeponet_fem_gaa.py):
2D 単位正方形上の GAA 断面（Si コア/酸化膜リングの可変 ε）で、
P1 FE を組み、弱形式損失でコールドスタート学習 → 移動/成長するガウス電荷
（電子パケットの再配置を模擬）を準定常ステップで流し、FE 誤差指標が閾値超過の
ステップだけ厳密 FE 解＋リプレイバッファで追学習する。

出力 `pi_deeponet_fem_gaa.png`:
- 上段: ε(x) / ρ / 予測 φ / 厳密 φ（FE オラクル）
- 中段: 3 スナップショットの予測 φ と |予測−厳密| 誤差マップ（=事後誤差の空間分布）
- 下段: 誤差指標の推移・厳密解トリガ率（累積）・対オラクル rel-L2・前半/後半トリガ率

**実測結果**（既定設定 `--n 17 --pretrain 1500 --tol 0.5 --steps 60 --loops 2`, seed 固定）:

| 指標 | 値 |
|---|---|
| 厳密 FE 解の起動 | **24 / 60 ステップ**（= 36 ステップは推論のみ、厳密解 60% 削減） |
| 厳密解トリガ率 | **前半 57% → 後半 23%**（軌道 2 周目=再訪で低下） |
| 対 FE オラクル rel-L2 | **平均 0.074**（推移も低下傾向, 図 下段） |

誤差指標（相対 Galerkin 残差）が周回とともに閾値 0.5 を割り込む頻度が増え、厳密解の
起動が減る一方、精度は ~7% を維持。**「弱形式演算子学習＋FE 誤差評価トリガ＋オンライン適応
で厳密ソルバ起動を減らす」**という主張が検証可能な形で示せている。
> これはあくまで**概念実証**であり、3D・量子補正・散乱・自己整合ドリフト拡散収束は含まない。
> 素の相対 Galerkin 残差は K が微分作用素のため解の誤差より過大に出る傾向があり（tol は
> それを見込んだ較正値）、より厳密には energy-norm 推定（∝ ‖e‖_K）や数回 CG 反復での
> 誤差推定に置き換えられる（「伸ばす軸」参照）。

```
python3 pi_deeponet_fem_gaa.py            # 学習＋オンラインデモ＋作図
python3 pi_deeponet_fem_gaa.py --help     # n, p, tol, steps, adapt_iters ...
```

## 2b. 弱形式 vs 強形式ベンチ — 新規性の一枚看板 [`bench_weak_vs_strong.py`](../bench_weak_vs_strong.py)

「なぜ弱形式が本質的に優れるのか」を、**ニューラル学習の最適化を挟まず**離散化レベルで示す。
可変誘電率 −∇·(ε(x)∇φ)=ρ（GAA 的な高κコア/低κ界面, 幅 δ）を 2 通りの厳密ソルバで解き、
細メッシュ FE 基準に対する rel-L2 を比較:

- **weak (FE Galerkin)**: 要素ごとに ε を積分して組み立てるため、界面のフラックス連続
  条件 [ε ∂φ/∂n]=0 が自然に入る。
- **strong (naive FD)**: 素朴な 5 点差分 ε_ij(4φ_ij−近傍)/h² = ρ_ij。∇ε·∇φ 項を落とす
  点ごとの強形式で、**強形式 PINN 残差 ε∇²φ=−ρ と同じ界面の扱い**（＝Otsuki & Mori が
  用いる FD の系統）。

**実測結果**（`--n_ref 49`, seed 固定）:

| | δ=0.03, mesh を細分化 (A) | n=13, 界面を鋭く (B) |
|---|---|---|
| **weak (FE)** | 0.130 → 0.039 → **0.0093**（O(h²) で収束） | 0.017 → **0.044** |
| **strong (FD)** | 0.562 → 0.554 → **0.556**（**収束せず頭打ち**） | 0.438 → **0.554** |

- **弱形式はメッシュ細分化で正しく収束**（O(h²)）。**強形式は解像度を上げても ~0.55 で頭打ち**
  — 界面のフラックス連続を破るため誤差が界面から全域に伝播する（図 下段: 強形式の誤差は
  全域で大、弱形式は界面近傍にごく小）。
- 界面が鋭いほど強形式の誤差が増大。

これが本アイデアの一枚看板: **「強形式(FD/PINN) は可変 ε 界面で系統誤差の床を持ち、弱形式(FE)は
これを解消する」**。Otsuki & Mori が FD で解く箇所を弱形式演算子学習に置く動機の定量的裏付け。
> 注: 束保存を守る FD（調和平均の面係数＝有限体積）なら収束する。ここで比較しているのは
> あくまで**点ごとの強形式**であり、要点は「点ごと強形式 ≠ フラックス整合な弱形式」。

```
python3 bench_weak_vs_strong.py           # 2つの掃引＋誤差マップ（bench_weak_vs_strong.png）
```

## 2c. 非線形ソルバのウォームスタート（アイデアC）[`fe_newton_warmstart.py`](../fe_newton_warmstart.py)

「定番（ML で TCAD 収束を加速）× 新規性（弱形式演算子）」の両取り。**FEM を精度の権威に
残し、ネットは Newton の初期値だけを与える**（置換でなく加速）。

- 問題: 1D 非線形ポアソン（Poisson–Boltzmann）$-\lambda^2 u''+\sinh(u)=d(x)$、
  P1 有限要素＋**減衰(ラインサーチ)付き Newton**（TCAD 標準の安全策）。
- コールド $u_0=0$ vs ウォーム $u_0=\text{net}(d)$（学習演算子 $d\mapsto u$）。
- オンライン: ドープ分布が流入 → ウォームスタートで解く → 収束解をバッファに追学習。

**実測結果**（既定, seed 固定）:

| | 平均 Newton 反復 |
|---|---|
| コールド (u₀=0) | 5.2 |
| ウォーム (net) | **3.7**（前半 3.9 → 後半 3.5, 適応で改善） |

**すべて厳密 FE 解**（精度は一切犠牲にしない）で反復のみ ~30% 削減。1D の穏やかな例なので差は
控えめだが、2D/3D・連立DD・バイアス掃引ではコールドの反復コストが跳ね上がり、ウォームの節約は
拡大する。実装上の注意: ネット初期値は float32 だと Newton 補正が tol 手前で丸め落ちするため
solver 内で **float64 に統一**（`newton_solve`）。

```
python3 fe_newton_warmstart.py            # 学習＋オンライン＋作図（fe_newton_warmstart.png）
```
