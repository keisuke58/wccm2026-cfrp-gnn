# 基礎資料：繊維強化樹脂の射出成形と残留ひずみ

> デンソー案件（[`DENSO_RA_RESIDUAL_STRAIN.md`](./DENSO_RA_RESIDUAL_STRAIN.md)）に着手するための
> 基礎知識の整理。本リポジトリの既存資産は連続繊維の積層板（CFRP/CFRTP）を対象としており、
> **射出成形・短繊維・流動誘起配向は扱っていない**。その差分を埋めることを目的とする。
>
> 記号：σ 応力、ε ひずみ、C 剛性テンソル、α 熱膨張係数テンソル、X_c 結晶化度、a_ij 配向テンソル、T 温度。

---

## 1. 材料の分類 — どこに位置する材料なのか

### 1.1 マトリクス樹脂
| | 熱硬化性樹脂 | 熱可塑性樹脂 |
|---|---|---|
| 固化機構 | **架橋反応**（不可逆） | **冷却による固化**（可逆、再溶融可） |
| 代表例 | エポキシ、不飽和ポリエステル | PP, PA（ナイロン）, PBT, PPS, PEEK, フッ素樹脂 |
| 収縮の起源 | 硬化収縮 + 熱収縮 | （結晶性なら）**結晶化収縮** + 熱収縮 |
| 成形 | オートクレーブ、RTM | **射出成形**、スタンピング |
| 本件 | — | **こちら**（入力に結晶化度があるため半結晶性と確定） |

熱可塑性樹脂はさらに **非晶性**（PC, PS, ABS）と **半結晶性**（PP, PA, PBT, PPS, PEEK）に分かれる。
結晶化度が問題になるのは半結晶性のみである。

### 1.2 繊維長による分類
| 分類 | 繊維長の目安 | 成形法 | 配向の扱い |
|---|---|---|---|
| 短繊維 (SFRP) | 0.2–1 mm | 射出成形 | **流動で決まる配向場** |
| 長繊維 (LFRP) | 1–25 mm | 射出成形（LFT） | 同上。繊維同士の相互作用が強い |
| 連続繊維 | 連続 | 積層・RTM・スタンピング | **積層角（設計値）** |

**本リポの既存資産は最下段（連続繊維・積層角）を前提としている。** 本件は上2段にあたり、
配向が「設計値」ではなく「流動の結果」である点が本質的な違いである。

## 2. 射出成形の工程

### 2.1 工程の段階
1. **可塑化**：スクリュで樹脂を溶融し計量する。
2. **充填 (filling)**：金型キャビティへ溶融樹脂を射出する。**ここで繊維配向が決まる。**
3. **保圧 (packing / holding)**：冷却収縮を補うため圧力をかけ、樹脂を追加供給する。
   **残留応力の符号・分布に強く影響する。**
4. **冷却 (cooling)**：金型内で固化させる。**ここで結晶化と熱収縮が進む。**
5. **離型**：拘束が外れ、残留応力の一部が変形（反り）として解放される。

「樹脂を流す速さ」＝射出速度であり、2 の段階を支配する。「金型温度」は 4 を支配する。
本件で調整対象とされているのはこの 2 つである。

### 2.2 ファウンテンフローとスキン–コア構造
充填中、流動先端では樹脂が中心から壁面へ噴き出すように広がる（**ファウンテンフロー**）。
この結果として板厚方向に層構造が生じる。

| 層 | 位置 | 配向の傾向 | 理由 |
|---|---|---|---|
| スキン層 | 表層 | **流動方向に強配向** | 壁面せん断が大きく、急冷で配向が凍結される |
| シア層 | 中間 | 流動方向配向が最大となることが多い | せん断速度が最大 |
| コア層 | 中心 | **流動直交方向寄り**になりやすい | 伸長流が支配的 |

**帰結：配向は点の値ではなく板厚方向のプロファイルである。** 表層と中心で別の材料とみなせるほど異なる。
計測点が表層か内層かで見ている対象が変わる、という本件の論点はここに由来する。

## 3. 結晶化 — 入力の一方

### 3.1 結晶化度
半結晶性高分子は結晶相と非晶相が共存する。結晶化度 X_c は結晶相の割合であり、
**結晶相の方が密度が高いため、結晶化が進むと収縮する**（結晶化収縮）。
弾性率・耐熱性も X_c とともに上昇する。

### 3.2 等温結晶化：Avrami 式
等温条件での相対結晶化度の発展は

```
X(t) = 1 − exp( −k t^n )                                    (1)
```

n は Avrami 指数（核生成と成長の次元に対応）、k は速度定数である。

### 3.3 非等温結晶化：Nakamura 式
実際の成形は冷却しながら進むため、非等温への拡張が要る。Nakamura 式は

```
X(t) = 1 − exp[ −( ∫₀ᵗ K(T(τ)) dτ )^n ]                      (2)
```

成形で効くのは速度定数 **K(T)** の温度依存性である。

### 3.4 K(T) の形 — Hoffman–Lauritzen
結晶化速度は Tg と Tm の間で最大となる**釣鐘型**を示す。これは次の競合による：
- **高温側**：過冷却度が小さく、核生成の駆動力が足りない → 遅い
- **低温側**：分子鎖の運動が凍結し、拡散できない → 遅い

Hoffman–Lauritzen の式はこの両端での消失を正しく表す：

```
K(T) = K₀ exp[ −U* / R(T − T∞) ] · exp[ −K_g / (T ΔT f) ]     (3)
       ΔT = T_m⁰ − T,   f = 2T / (T_m⁰ + T)
```

第1項が拡散（低温で消失、T∞ ≈ Tg − 30 K）、第2項が核生成（Tm⁰ で消失）を表す。

> **本リポに検証済みの実装がある。** `validation/cfrtp_peek_validation.py` において、
> 炭素/PEEK の公開データに対し、冷却速度に対する結晶化ピーク温度 Tp の低下、α(T) の低温側シフト、
> 急冷時の結晶化度低下を検定済みである。単純な釣鐘型 K(T) ではこれらを満たせないことも確認している。

### 3.5 成形における含意
**冷却速度が上がると結晶化する時間が足りず、結晶化度が下がる。**
その結果、収縮量・弾性率・残留応力がいずれも変化する。金型温度と肉厚が冷却速度を決めるため、
**金型温度 → 冷却速度 → 結晶化度 → 収縮 → 残留ひずみ** という因果が成立する。

## 4. 繊維配向 — 入力のもう一方

詳細は [`FIBER_ORIENTATION_TENSOR.md`](./FIBER_ORIENTATION_TENSOR.md) にまとめたので要点のみ。

- 配向分布 ψ(p) をモーメントで縮約した **配向テンソル a_ij = ∫ p_i p_j ψ(p) dp**（Advani–Tucker）で表す。
  対称かつ trace = 1、独立成分は 5。固有値が配向の強さ、固有ベクトルが主配向方向。
- 流動中の発展は **Folgar–Tucker 式**。4階テンソル a_ijkl が現れて閉じないため **閉包近似**が要る。
- 標準の Folgar–Tucker は濃厚系で配向変化を速く見積もりすぎるため、**RSC**（固有値の成長のみ遅らせる）
  や **ARD**（回転拡散をテンソル化）による補正が実務で使われる。
- **したがって解析で得られる配向場はモデルの産物であり、真値ではない。**

## 5. 残留応力と残留ひずみ — 本題

### 5.1 固有ひずみによる定式化
熱収縮や結晶化収縮のように、応力を伴わずに生じるひずみを**固有ひずみ** ε* と呼ぶ。構成則は

```
σ = C : ( ε − ε* )                                          (4)
ε* = α ΔT + β ΔX_c                                          (5)
```

α ΔT が熱収縮、β ΔX_c が結晶化収縮である。

**重要な区別**：自由に収縮できるなら σ = 0 で、ひずみだけが残る。
応力が生じるのは**収縮が拘束される場合に限る**。拘束の源は次の3つである：
1. **繊維による拘束**（ミクロ）：繊維と樹脂の熱膨張差。繊維はほとんど膨張しない。
2. **層間の拘束**（メソ）：配向の異なる層が互いに拘束し合う（スキン–コア）。
3. **金型による拘束**（マクロ）：離型までは金型が変形を拘束する。

### 5.2 射出成形品の残留応力の2種類
| 種類 | 起源 | 大きさ | 分布 |
|---|---|---|---|
| **流動誘起** | 充填時に配向した分子鎖が緩和しきらずに凍結 | 相対的に小さい | 表層に局在 |
| **熱誘起** | 冷却時の不均一な収縮 | **支配的** | 板厚方向に分布 |

熱誘起応力の典型的な機構：表層が先に固化し、後から内部が収縮しようとするが表層に拘束される。
結果として**表層が圧縮、内部が引張**となる分布が生じやすい。ただし**保圧条件によりこの符号は変わりうる**。

### 5.3 配向はどの経路で残留ひずみに効くか
式 (4)(5) から分かるように、配向は **α と C を通じてのみ**効く。
配向した複合材は熱膨張が異方的になる（繊維方向は小さく、直交方向は大きい）。
この異方性と拘束の組合せが残留ひずみを生む。

**この経路を特徴量にしたのが「配向平均した α_ij」である**（`fiber_orientation_cte.py` に実装）。
なお α は2階テンソルだが、配向の異なる領域が相互に拘束するため**直接平均してはならない**。
熱応力 C:α を平均し、平均剛性の逆を作用させる：

```
⟨α⟩ = ⟨C⟩⁻¹ : ⟨C : α⟩                                       (6)
```

### 5.4 計測法
残留応力・ひずみの計測は、多くが**解放ひずみを測る破壊的手法**である。これが
「点でしか測れない」理由である。

| 手法 | 原理 | 得られるもの |
|---|---|---|
| 層除去法 | 表層を削り、曲率変化を測る | 板厚方向分布 |
| 穴あけ法 | 小孔を開け、周囲の解放ひずみをゲージで測る | 孔位置での値 |
| 曲率法 | 非対称積層の反りから逆算 | 平均的な値 |
| X 線回折 | 結晶格子面間隔の変化 | **結晶相のみ**、表層 |
| DIC | 切断前後の表面変位 | 切断面近傍 |

## 6. なぜ機械学習を使うのか

プロセスから残留ひずみまでは **充填解析 → 配向発展 → 結晶化 → 粘弾性応力解析** の多段連成であり、
1ケースの計算コストが高い。条件探索や逆設計には多数ケースが必要となるため、
**計算結果を学習したサロゲートで高速化する**ことに意味がある。

ただし本リポの一貫した方針として、**精度の権威は物理解析と実測にあり、機械学習は加速層に留める**。
本件で転移学習を用いるのは、解析データ（量は作れるがモデル誤差を含む）と
実験データ（正確だが少数・点）の双方の性質を活かすためである。

| 用語 | 意味 |
|---|---|
| ゲート | 樹脂をキャビティへ導入する入口。位置が配向場を決める |
| ウェルドライン | 流動が合流した界面。繊維が界面を跨がず強度が低い |
| ヒケ (sink mark) | 内部収縮による表面のくぼみ |
| 反り (warpage) | 不均一収縮による成形品の変形 |
| 保圧 | 充填後に加える圧力。収縮を補償する |
| PVT 特性 | 圧力–比容積–温度の関係。収縮計算の基礎 |
| 繊維破断 | 可塑化・充填中に繊維が折れ、繊維長が短くなる現象 |
| 配向テンソル | 本文 §4 |
| スキン–コア | 本文 §2.2 |
| 固有ひずみ | 本文 §5.1 |
| MD（machine direction, 流動方向） | 樹脂が流れる方向。繊維は主にこの方向を向くため、MD の収縮・熱膨張は小さい |
| TD（transverse direction, 直角方向） | 板の面内で MD に直交する方向。MD より収縮・熱膨張が大きく、MD との差が反りの原因となる |
| 穿孔法（hole-drilling method） | 表面にひずみゲージを貼り、小穴を段階的にあけて解放されるひずみから残留応力を求める計測法（本文 §5.4）。既報では Ch.3 が MD、Ch.1 が TD、Ch.2 が 45° 方向 |
| 解放ひずみ（released strain） | 穿孔により残留応力が解放されてゲージに生じるひずみ。穿孔法の計測量 |
| 無応力温度 *T*<sub>0</sub> | 残留応力が生じ始めるとみなす温度。既報は解析で 180 °C とし、実測との合わせ込みでは約 120 °C と推定した |
| 転移学習（transfer learning） | 数値解析で事前学習したモデルを、少数の実測データで補正する手法 |
| L2-SP | 転移学習の正則化の一種。補正後のパラメータが事前学習の値から離れすぎないよう罰則を課す（Li et al., ICML 2018） |
