# 成形条件 → 繊維の向き（2026-11-08）

スクリプト：`validation/denso_flow_coupling.py`（結果 `results/denso_flow/coupling.json`）、
図：`slides/figure_sources/denso_flow_twozone_fig.py` → `slides/figures_paper/flow_twozone.png`。
これまでの 1 次元せん断モデル（`validation/denso_flow_orientation.py`）は確認に失敗している。
中心の層（a_yy > a_xx）が、既報 1.60 mm に対して 0.92 mm 以下にしかならなかった。

## 1. 繊維と流れの連成（失敗）
繊維の向きで粘度が変わる効果（Lipscomb 型、連成数 N_p 0–40）を入れた。
- 中心の層は 0.40 → 0.52 mm にしか広がらない（κ = 1、n = 0.3）。
- RSC（κ = 0.1）では、0.80 → 0.74 mm と、かえって狭くなる。
- 結論：**連成は、足りないものの正体ではない。**

## 2. 原因の手がかり：表側の層は固化層の厚さ
| | 既報 | 計算（配向データに合わせた数はない） |
|---|---|---|
| 3 mm 板：表側の層（上／下） | 0.79 / 0.60 mm | 固化層 0.71 mm（壁からの熱伝導、充填時間 1 s） |
| 3 mm 板：中心の層 | 1.60 mm | 1.64 mm |
| 3 mm 板：RMSE a_xx / a_yy | — | 0.21 / 0.19（1 次元せん断モデルの最良値は 0.35 / 0.29） |
| 1 mm 板：中心の層 | 0.19 mm | 0.24 mm（充填時間は厚さに比例と仮定） |

**2 層の規則**
- 充填中に固まった層（固化層）は、流れ方向にそろう。
- 充填の最後まで流れていた通り道（中心）は、ゲートの向き（横向き）のまま残る。

厚さの違う 2 枚の板で、同じ規則が成り立った。

3 枚目（Ricotta ら 2021、PPS/GF40、1.8 mm、金型 80 °C、流量 40 cm³/s → 充填 1.8 s、中心の層 約 0.15 mm）：
規則で 0.15 mm になるには、溶融樹脂が壁に触れている時間が 0.83 s（充填時間の 46 %）であればよい。
流れの先端が一定の速さなら、流路の約 54 % の位置の断面にあたる。断面の位置は論文に書かれていないので、
**矛盾はないが、確認にはならない**。せん断モデルは、通り道の中までせん断しすぎている。

## 3. 設計に使える形
中心の層の厚さは、固化層の厚さで決まる。固化層は、金型温度・樹脂温度・充填時間で決まる。
いずれも 3 mm 板、仮定した基準値のまわりで動かした値。

| 条件 | 固化層 | 中心の層 |
|---|---|---|
| 金型 130 / 150 / 170 °C | 0.75 / 0.71 / 0.67 mm | 1.58 / 1.66 / 1.75 mm |
| 充填時間 0.5 / 1 / 2 s | 0.50 / 0.71 / 1.01 mm | |
| 樹脂温度 310 / 320 / 330 °C | 0.79 / 0.71 / 0.65 mm | |

成形条件から繊維の向きを出す、最小の物理モデルになる。段階③では、学習の代わりか、学習の土台に使える。

## 4. 金型の上下の温度差 → 反り（`validation/denso_twozone_warp.py`）
2 層の規則で厚さ方向の向きを作り、反りは PPS の成形モデル（冷却、結晶化、粘弾性）で計算した。スパン 100 mm のたわみ。
- 上下 150 / 150 °C：向きは上下対称で、反りは 0（整合）。図から読んだ向きでは −2.85 mm。
- 上下の差に対して、反りはほぼ比例する。差 20 / 40 / 80 °C で ±0.38 / 0.76 / 1.69 mm（約 0.02 mm/°C）。**設計の手がかりになる。**
- 既報の表側の層の上下差（0.79 / 0.60 mm）を、この規則で金型温度の差だけで説明すると、194 / 106 °C（差 88 °C）が要る。
  呼び値は 150 / 150 °C なので、ありそうにない。上下差には、金型温度以外の原因がある（流れ、読み取り）。
  そのとき、反りは −1.79 mm で、読んだ向きの −2.85 mm の 63 %。
- 以前の値（110 / 190 °C で +0.48 mm）は、確認に失敗した 1 次元モデルによるもの。この規則では +1.69 mm。

## 5. 3 次元部品（Greif & Meyer の Moldflow データ）での確認：決着せず
手元の 10 形状で、充填時刻（Fill_time）と固化時刻（Freeze_time）を使って試した（`validation/greif3d_twozone_probe.py`）。
- 充填中に固まる点の割合は 0〜17 %。充填時間が 0.1〜0.7 s と短いため、多くの部品でほぼ 0。
- 充填時刻の勾配から求めた流れの向きでは、流れ方向の成分は 0.19〜0.36 にとどまった。成分の並びをどう仮定しても同じ。
  流れの向きの推定がうまくいっていない可能性がある。
- メッシュは、厚さ方向の要素が数個しかない。
- 結論：**このデータでは、規則を確かめることも否定することもできない。** 比べる相手も Moldflow の計算であり、実測ではない。
  次は、fifa での 3 次元の充填計算（GUIDE §20）。

## 示せていないこと
- なぜ通り道がゲートの向きのまま残るのかは、説明できていない。流動の先端（噴水流）や保圧での向き直しが候補。
- 充填時間（3 mm で 1 s）、固化温度 280 °C、熱拡散率は仮定。2 枚の板で確かめたのは**規則**で、これらの値ではない。
- ゲートでの向き（a0 = 0.20 / 0.70 / 0.10）も仮定。
- 確かめたのは 1 種類の材料・1 か所（ゲートから 50 mm）だけ。
- 3 次元部品（Greif & Meyer の Moldflow データ）での確認はまだ。厚さ方向の分布がデータにあれば、次に確かめられる。
